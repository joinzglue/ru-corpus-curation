# Автоматические методы фильтрации обучающих данных для моделей обработки естественного языка

Дипломная работа: сравнение методов фильтрации качества обучающих данных и их влияния на качество BERT-классификатора на трёх русскоязычных датасетах.

Цель — измерить, как индивидуальные и комбинированные методы очистки обучающей выборки влияют на метрики модели, и сравнить каждый метод со случайным удалением эквивалентного числа примеров.

## Методы

В работе реализованы и сравнены пять подходов к фильтрации:

1. **Confident learning** — поиск ошибок разметки через out-of-sample предсказания K-fold кросс-валидации.
2. **DataMaps** — картография обучающих данных: сбор динамики обучения по эпохам и категоризация примеров на easy / ambiguous / hard-to-learn.
3. **DS2** — Data Selection via Scoring (LLM-оценка качества примеров + курирование оценок).
4. **VBF — Voting-Based Filtering** — гибрид, объединяющий списки на удаление от Cleanlab / DataMaps / DS2 голосованием (стратегии пересечения и объединения).
5. **VCS — Verified Cosine Similarity** —  поиск близких пар, безусловное удаление дублей одного класса и удаление пар разных классов только при подтверждении другими методами.

| Baseline | 0.9353 | 0.6635 | 0.6444 |
| Cleanlab | 0.9320 | 0.6262 | **0.6578** |
| DataMaps | 0.9260 | 0.6297 | 0.6441 |
